# Сайт QazDefense

Node.js + SQLite, своя админка. Домен и хостинг пока не выбраны — сайт работает локально.

## Запуск

```
npm install
npm start
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin — логин и пароль в файле `.env` (создаётся при первом запуске).

## Как добавить кейс или новость

Админка → «Кейсы» (или «Новости») → «Добавить». Заполните поля, загрузите картинки, выберите статус «Опубликован» → «Сохранить». На сайте показываются только опубликованные записи; черновики видны только в админке.

## Где что лежит

- `data/site.db` — база (кейсы, новости, заявки, отрасли). Делайте копию этого файла и папки `uploads/`.
- `uploads/` — загруженные картинки.
- `src/content.js` — постоянные тексты: направления, отрасли, цены, этапы.
- `.env` — пароль админки и контакты (`CONTACT_PHONE`, `CONTACT_TELEGRAM`, `CONTACT_EMAIL`).

## Публикация на GitHub Pages

Опубликованная версия: https://qazdefense.github.io (репозиторий `qazdefense/qazdefense.github.io`, ветка `gh-pages`).

```
npm run publish -- public
```

Команда собирает готовые страницы из локальной базы (кейсы, новости) в `dist/` и выкладывает их в ветку `gh-pages`. Через минуту сайт обновится.

В опубликованной версии нет сервера: админка работает только локально, а вместо формы заявки показываются кнопки WhatsApp, Telegram, телефона и почты (заполните контакты в `.env`).

## Дорожная карта Базовода

Страницы `/solutions/bazovod` и `/solutions/bazovod/roadmap` берут этапы и задачи из закрытого репозитория `qazdefense/bazovod`: этапы там заведены как milestones («0.2 Первая версия: …»), задачи как issues со строкой `Кратко: …` в описании. Закрыли задачу или этап на GitHub, затем:

```
node scripts/roadmap-sync.js
npm run publish -- public
```

Скрипт пишет `src/roadmap/bazovod.json`. На сайт попадают только названия и строка «Кратко», ссылок на задачи нет.
