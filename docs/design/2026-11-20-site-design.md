# Сайт Team QazDef — дизайн

Согласовано с пользователем 2026-11-20.

## Зачем
Сайт продаёт: клиент (владелец супермаркета, АЗС, завода, автосалона и т. д.) должен с первого экрана почувствовать, что команде можно доверять, и оставить заявку. Команда сама ведёт контент — кейсы и новости — без правки кода. Домен и хостинг появятся позже; сайт должен работать локально и переноситься на VPS без переделок.

## Цели
- Главная, 5 направлений (1С и учёт, ИТ-инфраструктура, сайты и приложения, ИИ-агенты, дизайн и маркетинг), отраслевые решения, кейсы (список с фильтром по отрасли и направлению + страница кейса), новости (список + страница), бесплатный аудит 1С, контакты с формой заявки.
- Админка `/admin` с логином: кейсы, новости, заявки, справочник отраслей. Статус «черновик / опубликовано» — простая модерация.
- Кейс: заголовок, клиент (можно скрыть), отрасль, направления, задача, решение, результат, «→ результат» одной строкой, использованные решения (теги: 1С:УТ, Розница, …), обложка, галерея.
- Новость: заголовок, дата, анонс, текст, обложка.

## Не цели (пока)
- Казахская версия (только заложена: префикс `/kz` в маршрутизации, поле `lang`).
- Роли автор/редактор, многопользовательская админка.
- Деплой, домен, почтовые уведомления о заявках.

## Анти-цели
- Выдуманные кейсы, цифры, клиенты или контакты. Только явные заглушки.
- Кричащий «креативный» лендинг, разговорный или драматичный тон.
- Неровная вёрстка, системные шрифты вместо Manrope/Inter.

## Подходы (рассмотрены)
1. Статический генератор + Markdown/Decap CMS — дёшево, но пользователь выбрал свою админку.
2. Headless CMS (Strapi) — тяжело для такого сайта.
3. **Своя админка на Node.js + SQLite (выбрано пользователем)** — одно приложение, файл базы и папка загрузок, VPS в Казахстане.
4. PHP — работает на дешёвом хостинге, но PHP не установлен локально; пользователь выбрал Node.

## Решения
- Node 24, Express 5, шаблоны EJS (серверный рендер — индексируется поисковиками), встроенный `node:sqlite` (без нативных модулей), `multer` для загрузок, `marked` для текстов в Markdown.
- Вход: логин/пароль из `.env`, подписанная cookie сессии (HttpOnly, SameSite=Strict).
- Данные: `data/site.db`, картинки: `uploads/`. Оба вне git.
- Стиль: #13254A, #F3F6FB, акцент #2A5FD6, Manrope (заголовки) и Inter (текст), карточки 16px со строкой «→ результат». Иллюстрации из презентации (`public/img`).
- Подача: крупный первый экран с двумя кнопками (аудит / обсудить задачу), блок «как работаем», отрасли, открытые цены, пример отчёта аудита, витрина кейсов, новости.
- Анимация сдержанная: появление блоков при прокрутке, подъём карточек при наведении, компактная липкая шапка; отключается при `prefers-reduced-motion`.
- Мобильная вёрстка обязательна (ссылки часто открывают из WhatsApp).

## Решения на усмотрение исполнителя (отмечены как мои)
- Справочник отраслей — в базе, редактируется в админке; направления — фиксированные (это страницы сайта).
- Заглушки контактов: `[телефон]`, `[Telegram]` в одном файле настроек `config.js`.
- Начальные данные: 2 кейса-примера и 1 новость, явно помеченные «Пример — заполните в админке».
