# Сайт Team QazDef — план реализации

**Goal:** локально работающий сайт с публичными страницами и админкой для кейсов и новостей.
**Architecture:** Express 5 + EJS (серверный рендер), `node:sqlite` (файл `data/site.db`), загрузки в `uploads/`, сессия в подписанной cookie.
**Tech Stack:** Node 24, express, ejs, multer, marked, cookie-parser; тесты — `node --test`.
**Spec:** `docs/design/2026-11-20-site-design.md`

## Global Constraints
- Цвета #13254A / #F3F6FB / #2A5FD6; шрифты Manrope + Inter; карточки radius 16px со строкой «→ результат».
- Тон деловой и спокойный; никаких выдуманных кейсов, цифр, контактов — только заглушки.
- На сайт попадают только записи со статусом `published`.
- Анимация отключается при `prefers-reduced-motion`.

## Review Focus
1. Черновик не виден на сайте ни в списке, ни по прямой ссылке (404).
2. Фильтр кейсов по отрасли + направлению вместе; пустой результат показывает понятное сообщение.
3. Кейс без обложки/галереи/решений не ломает карточку и страницу.
4. Дубликат slug при создании — добавляется суффикс, а не ошибка.
5. Админка без входа редиректит на /admin/login; неверный пароль не пускает.

## Tasks
1. **Каркас и база** — `package.json`, `src/db.js` (`openDb(path)`, схема: industries, cases, news, leads; `slugify`, `uniqueSlug`), `src/seed.js`. Тест: создание кейса, уникальный slug, выборка только published.
2. **Публичные маршруты** — `src/routes/public.js`, `src/content.js` (тексты направлений, отраслей, цен), шаблоны `views/*`. Тест: GET всех страниц 200; черновик 404; фильтр.
3. **Админка** — `src/routes/admin.js`, `src/auth.js`; CRUD кейсов/новостей с загрузкой картинок, список заявок, отрасли. Тест: без входа 302; вход; создание кейса появляется в /cases.
4. **Формы заявок** — POST /contacts, /audit → таблица leads. Тест: заявка сохраняется, пустое имя/телефон — ошибка.
5. **Стили и анимация** — `public/css/site.css`, `public/js/site.js`; проверка в браузере 1440px и 390px.
